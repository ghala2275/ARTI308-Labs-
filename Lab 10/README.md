# SVM Classification - Iris Dataset

## Overview
This lab applies Support Vector Machines (SVM) to classify iris flower species using the Iris dataset.

---

## Tasks Performed
- Loaded and explored the dataset
- Visualized the data using Seaborn and Matplotlib
- Split data into training and testing sets
- Trained an SVM classifier using `SVC`
- Evaluated the model using:
  - Confusion Matrix
  - Classification Report
- Improved performance using `GridSearchCV`

---

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Conclusion
The SVM model successfully classified the Iris dataset with high accuracy, and GridSearchCV helped improve the model performance.
