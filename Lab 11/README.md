# Credit Card Customer Segmentation

## Overview
This project uses K-Means clustering to group credit card customers based on spending behavior and financial activity.

---

## Tasks Performed
- Data cleaning and preprocessing
- Feature scaling
- K-Means clustering
- Elbow Method and Silhouette Score analysis
- Customer segment visualization

---

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## Files Included
- `02_Credit_Card_Customer_Segmentation_Assignment.ipynb`
- `README.md`

---

## Conclusion
The model successfully identified different customer groups, including high-value customers and customers with high cash advance usage.
